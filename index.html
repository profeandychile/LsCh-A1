¿Cómo funciona?

1. Registra a cada estudiante.

2. Selecciona su perfil y la etapa de aprendizaje.

3. Marca el aprendizaje cuando lo demuestre.

4. Asigna entre 100 y 1.000 puntos, de 100 en 100.

5. Acumula puntos y desbloquea insignias.

El puntaje es una recompensa educativa. Ajusta los apoyos y las oportunidades de práctica a las necesidades de cada estudiante.

📲 Tarjetas NFC

Genera un enlace individual desde la ficha de cada estudiante y prográmalo en su tarjeta NFC.

En un iPhone compatible, la tarjeta puede abrir una notificación con el enlace. El usuario normalmente debe tocarla para abrir la página.

Esta versión guarda los datos en el navegador. Un enlace NFC no sincroniza perfiles entre teléfonos. Para uso compartido en varios dispositivos se necesita una base de datos protegida.
