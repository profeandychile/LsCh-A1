📌 Cómo funciona

1. Registra al estudiante.

2. Abre su perfil y selecciona una etapa.

3. Marca los aprendizajes demostrados y asigna un puntaje.

4. El sistema acumula puntos y entrega insignias al cumplir metas.

Los puntos e insignias son una herramienta de motivación. Evalúa el aprendizaje observado, no la velocidad ni la conducta del estudiante.

💾 Respaldo de datos

La restauración reemplaza los datos actuales de esta aplicación. Exporta una copia antes de restaurar. Los datos no se sincronizan automáticamente entre celulares o navegadores.

Tarjetas NFC

Genera un enlace individual para cada estudiante. Programa ese enlace en una etiqueta NFC usando una herramienta compatible. En iPhone, al leerla, se puede mostrar una notificación que abre el enlace al tocarla.

El enlace no contiene el nombre del estudiante. No escribas información sensible en la tarjeta. Quien tenga el enlace podría intentar abrir el perfil.
